# Field Hours

A self-directed computer science study bulletin. Ten graduate courses and a capstone stand in for the work of a 36-credit master's (1,080–1,200 hours). Twelve undergraduate prerequisites sit outside that count. The rest of the taught catalog is on the site as well.

This is not a degree, not university credit, and not affiliated with Texas A&M University.

## Run it

```bash
npm install
npm run dev
```

Open the local site and start from the bulletin, the catalog, or Prerequisites.

## What is in the repo

Lectures, problems, PDFs (`public/notes`), and a spoken video for every lecture (`public/media`) are included. The media folder is large. A clone takes time and disk.

Seminars, research hours, and the internship number are catalog entries only. They are not lecture courses.
